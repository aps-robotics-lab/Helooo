# RoboKriti 2026 — Nova UI

GitHub Pages-ready static website. No Python, Flask, Firebase, Workers or server required.

## Design
- Completely refreshed visual system across public, registration, help, rules, arena and private portal pages.
- Editorial robotics aesthetic with technical grid, glass surfaces, cyan/violet energy, scroll reveals, route transitions and subtle 3D hover motion.
- Responsive and reduced-motion friendly.

## GitHub Pages
Publish the contents of this folder as the repository root (or configure GitHub Pages to use the folder containing `index.html`).

The site keeps clean directory URLs and does not require `.html` in the address bar. GitHub Pages serves directory `index.html` pages naturally.
